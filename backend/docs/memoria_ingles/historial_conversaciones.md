### Actividad #1
- **Fecha**: 2026-06-16
- **Tipo**: Simulacro de examen / Evaluación Adversarial[cite: 4]
- **Situación / tema**: Reporte técnico de actividades diarias a un Project Manager y resolución inmediata de un incidente crítico en un canal corporativo de comunicación.[cite: 1, 4]
- **Registro usado**: Mixto (Formal escrito para el reporte / Informal directo para la simulación de chat técnico)[cite: 4]
- **Estructures gramaticales activadas**: Pasado simple de verbos regulares técnicos, estructuras de futuro planeado ("going to"), e infinitivos de propósito.[cite: 1]
- **Vocabulario nuevo activado**: Critical database issue, memory leak, refactor queries, dashboard loading time, broken endpoint, restore service.[cite: 1, 4]
- **Errores frecuentes durante la actividad**: Interferencia del "for + infinitivo" en el bloque formal y omisión sistemática del artículo determinado técnico.[cite: 1, 4]
- **Nivel de autonomía del estudiante**: Alta autonomía. El estudiante estructuró de manera independiente las ideas y resolvió con precisión los requerimientos de los sujetos sin asistencia intermedia.[cite: 4]
- **Notas del tutor**: Destacada capacidad del estudiante para cambiar de registro y adoptar terminología de alto impacto profesional (use de "issue" y "resolve" ante situaciones de infraestructura), mostrando el éxito de la fase de exploración cultural previa.[cite: 1]
